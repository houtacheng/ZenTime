macOS 首次開啟方式

若出現「已損毀，無法打開」

  1. 打開 macOS 的「終端機」。
  2. 輸入下方指令，並在最後保留一個空格：xattr -dr com.apple.quarantine
  3. 不要自己輸入 App 路徑。直接從 Finder 將 靜心主持台.app 拖進終端機視窗。
  4. 確認畫面出現完整路徑後，按下 Enter，再重新開啟 App。

畫面會類似：xattr -dr com.apple.quarantine "/Users/你的名稱/Downloads/靜心主持台.app"

此步驟只需對你信任、且由本網站下載的 ZenTime 安裝檔操作。
