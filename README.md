# ZenTime 靜心主持台

ZenTime 是供靜心活動主持人使用的 macOS／Windows 雙視窗控制 App。主持台負責時間、聲音與畫面設定；乾淨的 16:9 參與者視窗可供 Zoom 分享或第二螢幕投影。

- 官方網站：<https://houtacheng.github.io/ZenTime/>
- 最新版本：<https://github.com/houtacheng/ZenTime/releases/latest>
- 跨平台主程式位於 `cross-platform/`
- Bitfocus Companion 模組位於 `companion-module-meditation-host/`
- QNAP／Docker 網頁版位於 `docker-version/`
- `Sources/` 為早期原生 macOS 版本原始碼

## QNAP Docker 網頁版

`docker-version/` 提供主持台、16:9 參與者畫面、手機控制頁、既有 Companion API，以及 WiiM Pro 播放控制。WiiM 的位址與音檔資料夾網址都由環境變數設定，程式沒有預設任何裝置。詳細部署方式請參考 `docker-version/README.md`。

## 使用方式

1. 雙擊 `靜心主持台.app`。
2. 在直式主持台設定文字、背景、時間、倒數與聲音。
3. 拖曳 16:9 視窗的空白處可移動整個視窗；拖曳文字或倒數可改變各自位置，拖曳時會出現水平、垂直與中央參考線。
4. 在 Zoom 的「分享螢幕」中選擇該 16:9 視窗。
5. 按主持台的「開始」。

預選時間包含 3、5、7、10、15、20 分鐘。切換時間後，主持台和參與者畫面的倒數會立即同步。三組聲音各有加寬的獨立音量滑軌與百分比，并分別提供「淡入」和「淡出」選項。背景音樂可不選。

字體選單會讀取本機已安裝的全部字體。文字框寬度、文字大小、倒數大小皆可調整。參與者視窗也可選擇永遠顯示在最上層。

字體選單顯示字體的正式顯示名稱；大小欄可直接輸入 8–300 的任意數值。控制台最上方固定為時間、倒數與現場控制。參與者倒數另有獨立字體選單，時間也可輸入自訂分鐘。

「文字區域寬度」是長句可使用的最大橫向範圍；調小會較早換行，短文字不會有明顯差異。

背景可使用純色、圖片或雙色漸層。參與者倒數可搭配圓環或直線進度動畫，並可設定進度的起始色與結束色，形成漸層效果。

倒數進度採累積顯示：開始時為空，直線由左往右增加，圓環由頂端順時針增加，時間結束時填滿。

App 內建 `磬聲.m4a` 作為開頭與結尾磬聲。可分別選擇其他音檔，也可按「恢復使用內建磬聲」。勾選「無聲模式」會略過開頭磬聲、背景音樂與結尾磬聲。

按「切換到選單列模式」後，普通視窗會收起並展開選單列控制台；按「切換到一般視窗模式」才會返回視窗。兩種模式完全手動切換。選單列模式開啟檔案、字體或顏色選擇器時，控制台會保持開啟。

拖曳文字或倒數時，畫面會顯示 4×4 的 16 格參考線。接近格線或另一個物件的中心、左右邊緣、上下邊緣時會自動吸附，並提供觸覺回饋。

## 熱鍵

- `Return`：開始或繼續
- `空白鍵`：暫停或繼續（文字輸入時不觸發）
- `Esc`：提早結束目前靜心
- `Command-R`：重新準備
- `Command-Shift-D`：顯示或隱藏參與者倒數
- `Command-Shift-T`：切換參與者視窗最上層
- `Control-Command-F`：參與者視窗全螢幕
- `Command-,`：顯示完整設定
- `Command-H`：隱藏 App
- `Command-Q`：結束 App

控制台內與「輔助說明」選單皆可開啟熱鍵說明畫面。滑鼠移到 Mac 頂端選單列時，參與者視窗會被帶到最前方，方便快速找到。

## 重新建置

執行 `./build-app.sh`，完成後會在本資料夾產生新的 `靜心主持台.app`。

## API 與 Companion

App 啟動後會在本機 `4747` 連接埠提供控制 API。狀態端點是 `/api/state`；控制端點包括 `/api/start`、`/api/pause`、`/api/toggle`、`/api/reset`、`/api/finish` 與 `/api/duration?minutes=12`。

主持台的「網頁控制：開啟」會打開響應式網頁控制台，網址是 `http://127.0.0.1:4747`。同一 Wi‑Fi 的手機或平板，可將 `127.0.0.1` 換成 Mac 的區域網路 IP 位址。

可直接匯入 Companion 的安裝包位於專案根目錄：`靜心主持台-Companion模組-0.2.0.tgz`。在 Companion 的 Modules 頁面選擇「Import module package」並選取該檔案即可，不需解壓縮。
